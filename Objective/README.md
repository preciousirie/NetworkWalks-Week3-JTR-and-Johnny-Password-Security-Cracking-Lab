# Project Objectives
## Week 3 – Project Module 2: Password Cracking with JTR and Johnny

**Programme:** Network Walks Cybersecurity Internship  
**Batch:** B084  
**Operating System:** Host Windows OS

### 1. Project Purpose

The purpose of this project is to develop practical knowledge of password recovery and password security using John the Ripper (JTR) and Johnny in a controlled, instructor-authorized exercise.

The project focuses on understanding the tools, their roles, the recovery workflow, and the importance of verifying results against the supplied password-protected ZIP archive.

### 2. Learning Objectives

By completing this project, the following learning objectives are addressed:

1. **Understand password security:** Develop an understanding of why passwords protect files and how password strength affects security.

2. **Understand John the Ripper:** Become familiar with JTR as a password-auditing and recovery tool.

3. **Understand Johnny:** Explore Johnny's graphical interface and how it provides access to selected John the Ripper functionality.

4. **Understand the recovery workflow:** Learn the general stages involved in an authorized password-recovery exercise.

5. **Verify results:** Confirm whether a recovered password successfully unlocks the instructor-provided ZIP archive.

6. **Collect technical evidence:** Preserve relevant screenshots and observations that demonstrate the project stages and outcome.

7. **Document findings:** Present the exercise in a clear, structured, and technically accurate format.

### 3. Tools and Requirements

| Tool or Component | Purpose |
|---|---|
| Windows OS | Project operating environment |
| John the Ripper | Password-recovery exercise |
| Johnny | Graphical interface for JTR |
| Instructor-provided ZIP archive | Authorized test file |
| GitHub | Project documentation and evidence |

### 4. Project Scope

The scope of this project is limited to:

- The instructor-provided assignment materials.
- The assigned Windows environment.
- John the Ripper and Johnny.
- The supplied password-protected ZIP archive.
- Documentation of the authorized exercise and its results.

No unrelated personal files, accounts, archives, or third-party systems are included.

### 5. Expected Learning Outcomes

At the end of the project, the learner should be able to:

- Explain the basic purpose of John the Ripper and Johnny.
- Describe the distinction between a password-recovery tool and its graphical interface.
- Explain why password strength matters.
- Describe the stages of an authorized password-recovery exercise.
- Verify a recovery result using the supplied test archive.
- Produce professional technical documentation supported by evidence.

### 6. Evidence and Documentation

The project evidence should demonstrate relevant stages of the exercise, including:

- Tool installation and configuration.
- The authorized exercise environment.
- Relevant processing and recovery evidence.
- The verification result.
- Supporting screenshots and observations.

Recovered passwords and assignment flags should not be published in the repository unless the instructor explicitly permits their disclosure.

### 7. Ethical and Authorization Boundaries

This project is strictly for educational purposes. All testing must remain within the instructor-authorized exercise.

The tools must not be used to access files or systems without the owner's permission.

### 8. Project Completion

The reported exercise outcome was successful verification of the supplied ZIP archive using the recovered password, followed by capture of the assignment flag.

The public documentation will record the outcome without exposing the recovered password or flag value.
