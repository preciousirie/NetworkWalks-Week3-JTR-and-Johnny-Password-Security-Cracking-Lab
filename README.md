# Network Walks – Week 3, Project Module 2
## Password Cracking with John the Ripper (JTR) and Johnny

**Programme:** Network Walks Cybersecurity Internship  
**Batch:** B084  
**Project Module:** Week 3 – PM2  
**Operating System:** Windows  
**Tools:** John the Ripper (JTR) and Johnny

### Project Overview

This project explores password recovery concepts through an instructor-authorized cybersecurity exercise using John the Ripper (JTR) and its graphical interface, Johnny.

The exercise involves working with an instructor-provided password-protected ZIP archive, using the assigned tools to perform the password-recovery exercise, and verifying the recovered password against the supplied archive.

The project is conducted strictly for educational purposes within the scope of the Network Walks internship assignment.

### Objectives

- Understand the fundamentals of password security and password recovery.
- Become familiar with John the Ripper and Johnny on Windows.
- Understand the role of password-protected archives in security testing.
- Learn how password-recovery tools are used in an authorized laboratory exercise.
- Verify the recovery result using the instructor-provided ZIP archive.
- Document the process, observations, and evidence professionally.
